# 卵どろぼう（Egg Thief）設定ガイド

人気の「卵を盗む」系ゲームを参考にした、オリジナルのRobloxゲームです。
マップ・ベース・卵はすべてスクリプトが自動で作るので、Studioでの手作業は **スクリプト3つを置くだけ** です。

## 遊び方
1. 参加すると自分のベース（色つきの囲い）に出現します。
2. 中央の **卵畑** で卵に近づき **E** で拾う → 自分のベースに入ると台に置かれます。
3. 卵は7つのレア度（コモン・普通・レア・エピック・ミシック・神・810）× 5種類の柄 × 4色。レアほど光ったりキラキラし、810の卵は炎をまといます。**810の卵は卵畑に1日1個だけ**出ます（日本時間の0時にリセット。セーブがONなら全サーバー合わせて1日1個）。
4. 自分の台の卵で **E長押し → 開ける**。卵が揺れて割れ、中から **生き物** が生まれます（全28種類）。生き物は卵よりたくさんお金を生みます。
5. 自分の生き物で E長押し → **売る**（まとまったお金）。
6. 他の人のベースの台で **E長押し** → 卵や生き物を **盗む**。持っている間は少し遅くなります。
7. **F** キー（スマホは「押す」ボタン）で近くの人を押す → 持っているものを落とさせる。盗まれたものは持ち主の台に戻ります。
8. 持っているものは **G** キー（または「落とす」ボタン）でいつでもその場に落とせます。
9. 左下の **コード入力欄** に `114514810` と入れて「使う」を押すと、810の卵がもらえます（何回でもOK）。**このコードは管理者専用**です（ゲームの持ち主と、`EggConfig` の `AdminUserIds` に入れた人）。ほかのコード：
   - `うんこです`（**管理者専用**）→ **飛べる**ようになる。操作は**マイクラのクリエイティブ飛行**と同じ：ジャンプを2回すばやく押すと飛ぶ／もう一度2回押すと着地。スティック（WASD）で水平に360度、歩く速さの12倍でなめらかに飛ぶ（カメラを上下に向けても高さは変わらない）。**ジャンプ長押しで上昇**、**しゃがむで下降**（パソコンは Ctrl か Q、スマホは飛行中に出る「しゃがむ」ボタンを長押し）。スマホは飛んでいる間、**左下に丸い「飛ぶスティック」**が出るので、指で押したまま動かした方向へ進む（上へずらすと前、下へずらすと後ろ）。体は進む方向へ360度傾き（前へは前のめり、後ろへは反り返り、横へは横倒し）、後ろへ進んでも振り向かずにそのまま下がる。
   - `2895sh21`（**インデックスを全部そろえた人だけ・1人1回だけ**）→ 810の卵がもらえる。使ったことはセーブされます。
   - `インムキング`（だれでも）→ 毎秒の収入が **2倍**（重ねがけなし）
   - どちらも、そのプレイ中だけ有効です（抜けるとリセット）。コードは `EggGameServer` の `CODES` で増やせます。
10. 右のボタンで **台を増やす**・**スピードUP**（速さ100まで・Lv28が最大）・**ベースをロック**（20秒間だれも入れない）。ベースには屋根と窓があります。
11. 右の **インデックス** ボタンで生き物図鑑が見られます。卵を開けて生まれた生き物（盗んで台に置いた生き物、台にいる生き物も）が登録され、まだの生き物は「？？？」。全28種類そろうと、ごほうびコード `2895sh21` が表示されます。
12. **天気イベント**：1時間に1回、5分間。画面の上に「次のイベントまで 42:10」のように残り時間が出ます（イベント中は「あと 3:20」）。雪・雨・雷・太陽からランダムで、**10%の確率で「異変」**（空があやしい紫色になり、効果がパワーアップ）。
   - ❄ 雪：卵畑の卵が2倍の数・2倍の速さで出る（異変は3倍）
   - ☔ 雨：毎秒の収入が1.5倍（異変は3倍）
   - ⚡ 雷：卵畑のまわりに雷が落ち、近くで物を持っている人は落とす（異変はベースのあたりまで、雷がたくさん）
   - ☀ 太陽：レア以上の卵が2倍出やすい（異変は5倍）
   - 管理者はコード `イベント` ですぐに始められます（テスト用）。間隔や長さ、異変の確率は `EggConfig` の `EventInterval`・`EventDuration`・`EventAnomalyChance` で変えられます。
13. **OGイベント**（管理者専用）：マップの端（1番目と2番目のベースの間の外側）にある虹色のボタンを管理者が押すと、10分間のOGイベントが始まります。
   - 卵畑に **大きな虹色のOGの卵**（ふつうの10倍の大きさ、まわりに虹色のオーラ）が1個出ます。だれかが取ると、30秒後に次が出ます。イベントが終わると、残っている卵は消えます。
   - OGの卵からは **いちごゾウ**（いちごのからだのゾウ）が生まれます。からだが虹色に光り、炎・キラキラ・光の輪・王冠・星・大きな羽・虹色のオーラが全部ついています。稼ぎは **毎秒 10B（100億）**、レア度は **OG**。
   - OGはインデックスには数えません（限定のため）。大きさ・時間は `EggConfig` の `OGEggScale`・`OGEventDuration`・`OGEggRespawn` で変えられます。

### 生き物一覧
| レア度 | 生き物 |
|---|---|
| コモン | ピヨまる、モチうさ、コロガメ、ミケネコ、ポチイヌ、コグマ、ペンペン、ブーブー、ケロケロ、**コリュウ（龍・1%）**（10種類とも稼ぐ量は同じ） |
| 普通 | プルスライム、ツノトカゲ、フワクラゲ |
| レア | ホシネコ、メカクマ、ハナドラ |
| エピック | ヒノトリ、コオリオオカミ、ニジクジラ |
| ミシック | ギャラクシードラゴン、オウサマスライム、コスモノヴァ |
| 神 | カミフクロウ、ライジンリュウ、オーロラウサギ |
| 810 | 810キング、ムゲンスライム、ヤミノカミ |
| OG（限定） | いちごゾウ |

生き物の形・色・パーツは `EggConfig` の `Config.Species` で自由に変えたり、増やしたりできます。

## Studioでの設定（5分）
1. **New → Baseplate** で新しい場所を作る。
2. Explorer の **ReplicatedStorage** を右クリック → Insert Object → **ModuleScript**。名前を `EggConfig` に変え、中身を [EggConfig.lua](EggConfig.lua) で置き換える。
3. **ServerScriptService** を右クリック → Insert Object → **Script**。名前を `EggGameServer` にし、中身を [EggGameServer.server.lua](EggGameServer.server.lua) で置き換える。
4. **StarterPlayer → StarterPlayerScripts** を右クリック → Insert Object → **LocalScript**。名前を `EggGameClient` にし、中身を [EggGameClient.client.lua](EggGameClient.client.lua) で置き換える。
5. 上部 **File → Game Settings → Places**（または公開後の設定）で **最大人数を 8** にする（ベースが8個のため）。

完成形のExplorer：
```
ReplicatedStorage
  └ EggConfig        (ModuleScript)
ServerScriptService
  └ EggGameServer    (Script)
StarterPlayer
  └ StarterPlayerScripts
      └ EggGameClient (LocalScript)
```
※ 名前の `EggConfig` はスペルを正確に。他の2つの名前は自由です。

## テスト方法
- 1人で確認：上部 **Play**（F5）。卵を拾ってベースに置き、お金が増えるか見る。
- 盗む・押すの確認：**Test** タブ → **Clients and Servers** で人数を **2** にして **Start**。2つのウィンドウで盗み合えます。
- うまく動かないときは **View → Output** を開いて赤い文字を確認してください。

## セーブ（任意）
お金・台・卵を保存できます。Studioで試すには、ゲームを一度 **公開(Publish)** してから
**Game Settings → Security → Enable Studio Access to API Services** をON。
OFFのままでも遊べます（保存されないだけ）。

## 調整したいとき
数字はすべて `EggConfig` にあります。例：
- 卵の出やすさ・収入・色 → `Config.Rarities`
- 生き物の種類・形・収入 → `Config.Species`
- 台の値段 → `SlotCostBase` / `SlotCostGrowth`
- ロック時間 → `LockDuration` / `LockCooldown`
